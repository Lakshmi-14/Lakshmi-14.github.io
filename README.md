# Google Spreadsheet Data Viewer

This is a simple web application that fetches data from a Google Spreadsheet and displays it in a table format.

## How to Use

1. Replace `your_spreadsheet_id_here` in `script.js` with your Google Spreadsheet ID.
2. Push the code to a GitHub repository.
3. Enable GitHub Pages in the repository settings.
4. Access the application via `https://<username>.github.io`.

## Features

- Fetches data from a public Google Spreadsheet.
- Displays data in a responsive HTML table.
